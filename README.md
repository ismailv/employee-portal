📘 Employee Management App (Lit + LocalStorage)

A simple yet elegant Employee Management Application built using Lit
.
The app demonstrates how to manage data locally (via localStorage) with a clean, responsive UI, including CRUD operations and client-side routing — all without any external backend.

🚀 Features

✅ Create / Edit Employees
Add new employees or edit existing ones using a user-friendly form.
Validation is included for required fields, email, phone number, and date inputs.

✅ Employee List View
Displays all employees in a paginated card layout (10 per page).
Each card shows employee details and provides Edit and Delete actions.

✅ Delete Confirmation Modal
When deleting an employee, a modal confirms the action to prevent accidental deletions.

✅ LocalStorage Persistence
Employee data is stored locally, so it remains even after page refreshes.

✅ Routing via Hash URLs
The app uses a lightweight client-side router (#/employee/:id or #/employee/new) for navigation between the list and form views.

✅ Responsive Design
The layout adapts to all screen sizes with a modern, mobile-friendly grid system.

✅ Localization Ready
The project structure supports Lit Localize
 for multilingual support.
